# Frontend — Centro Integral

Angular 22 (componentes standalone, signals).

```bash
npm install
npm start          # http://localhost:4200, /api va al backend en :3000 (proxy.conf.json)
```

- Tests: `npx ng test --watch=false`
- Lint: `npm run lint` (angular-eslint)
- URL de la API: `src/environments/`
